# Kebijakan Keamanan (Security Policy)

Keamanan data *world-building* dan privasi pengguna adalah prioritas tertinggi di EPOS. Kami memperlakukan setiap *lore*, kerangka cerita, dan draf tulisan Anda sebagai kekayaan intelektual (IP) yang sangat berharga.

## Versi yang Didukung

Saat ini, kami hanya menyediakan pembaruan keamanan untuk versi mayor terbaru dari EPOS:

| Versi | Didukung (Supported) |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Melaporkan Celah Keamanan (Reporting a Vulnerability)

**TOLONG JANGAN MELAPORKAN CELAH KEAMANAN MELALUI PUBLIC GITHUB ISSUES.**

Jika Anda menemukan celah keamanan, *exploit*, atau titik lemah dalam sistem autentikasi/database kami, silakan laporkan secara rahasia melalui email ke:

📧 **security@epos-app.com**

Sertakan detail berikut dalam laporan Anda:
1. Jenis kerentanan (misalnya: XSS, SQL Injection, Bypass Auth).
2. Langkah-langkah detail untuk mereproduksi masalah tersebut.
3. Potensi dampak jika kerentanan tersebut dieksploitasi.

Kami akan memberikan konfirmasi penerimaan laporan Anda dalam kurun waktu 48 jam dan terus mengabarkan status penyelesaiannya secara berkala.

## Pembaruan Keamanan
Jika ada *patch* keamanan krusial yang perlu diterapkan, kami akan mempublikasikan *Security Advisory* di GitHub dan menyarankan semua *developer* yang melakukan *self-host* untuk segera memperbarui repositori mereka.
